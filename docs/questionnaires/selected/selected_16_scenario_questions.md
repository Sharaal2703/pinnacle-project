# MindBridge Scenario-Based Questions (16 items, Classes 6–8)

**Structure:** 16 scenario questions, each with 4 options. Each option carries one VARK type and one or more Multiple Intelligence (MI) types.

**How to read the tables:** the student picks the option that best matches how they would act. There are no right or wrong answers, and the VARK and MI labels stay on the server and are never shown to students.

**Note:** The question and option wording is copied word for word from the three source questionnaires. The VARK and MI labels are the corrected mappings from the earlier review. They are proposed interpretations, not validated scoring keys.

## Coverage check

Every question has exactly one option of each VARK type (V, A, R, K), so each VARK type appears 16 times.

| MI type | Options carrying it | Questions it appears in |
|---|---|---|
| Linguistic | 30 | 16 of 16 |
| Logical-Mathematical | 10 | 7 of 16 |
| Spatial/Visual | 20 | 15 of 16 |
| Musical | 2 | 2 of 16 |
| Bodily-Kinesthetic | 10 | 10 of 16 |
| Naturalistic | 4 | 1 of 16 |
| Interpersonal | 11 | 10 of 16 |
| Intrapersonal | 5 | 3 of 16 |

## Things to know before using these

1. **Linguistic is over-represented.** Both the Aural (A) and Read/Write (R) options map to Linguistic, so it appears in all 16 questions. Musical (2 questions) and Naturalistic (1 question) are thin because the source questionnaires hardly ask about them. The 24 self-report questions cover all eight types (3 each). Consider writing a few original scenarios about sound, rhythm, nature and the outdoors.
2. **Original wording is required.** Design §3.5 says question text must be original and must not be copied from websites without permission. The VARK questionnaire has its own copyright terms. Use these as a model and rewrite them in your own words, or get permission, before release.
3. **Mixed voice.** Some questions say "I would" and others say "you would". Pick one when rewriting.
4. **Mapping contributions are not set yet.** Each option needs a 0–1 contribution per MI type. A simple default is 1.0 for a single type and 0.5 each when an option has two types.
5. **Teacher review and pilot test.** A teacher should read every question, and the set should be tried with a small group of Class 6–8 students.
6. **Presentation.** Mix the order of the questions and of the options for each session.
